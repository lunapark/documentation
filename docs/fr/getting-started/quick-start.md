# Démarrage rapide

## Le tutoriel gamifié

Le meilleur moyen de se lancer dans Luna Park est de suivre les exercices disponibles dans l'onglet [Challenge](https://luna-park.app/challenge).

Ce tutoriel sous forme de jeu vous permettra de découvrir les fonctionnalités de Luna Park de façon ludique et interactive. Vous pourrez ainsi vous familiariser avec l'interface et les concepts de base du framework.

Chaque niveau vous propose un défi sur un aspect particulier de Luna Park. Sa résolution vous permettra de débloquer d'autres niveaux et de progresser dans votre apprentissage.

## L'académie

Une fois le challenge passé, nous vous conseillons de passer dans l'onglet [Académie](https://luna-park.app/academy) et découvrir un cas pratique étape par étape.

## Essayer sans compte

L'[éditeur playground](https://luna-park.app/editor) fonctionne sans connexion. La sauvegarde enregistre tout le projet dans l'URL de la page : vous pouvez le partager en copiant le lien.

## Votre première interaction

Prêt à construire ? [Votre première interaction](./first-interaction) vous guide pas à pas pour créer un bouton qui affiche un message, en 5 étapes.

## La version cloud

Inscrivez-vous sur la [page d'accueil](https://luna-park.app/) pour utiliser Luna Park dans votre navigateur. Votre tableau de bord liste vos projets.

### Créer un projet

Cliquez sur **Create a new project**, choisissez un emoji, un titre et un modèle :

| Modèle | Contenu |
|---|---|
| Empty project | Aucun fichier et aucun plugin. |
| Landing page | Un site vitrine d'une page construit avec les plugins Gradient et Motion, avec un formulaire de liste d'attente relié à une route et une table de base de données. |
| Nuxt project | Le plugin Nuxt UI installé et configuré. |
| Testing project | Un projet minimal utilisant la réactivité, le backend, la base de données et les cookies. |

### Offres

| Offre | Pour | Principales limites |
|---|---|---|
| Free | Communauté | Pas d'usage commercial, badge « Made with » sur les exports, pas de téléchargement du code source, pas d'éditeur desktop. |
| Pro | Particuliers | Tout. |
| Org | Organisations | Tout. |
| Edu | Éducation | Tout. |

## La version desktop

Luna Park existe aussi en application desktop (en bêta), pour travailler sur des dossiers de projet locaux, lancer les projets en local et créer des applications natives. Voir [Application Desktop](./desktop-app).
