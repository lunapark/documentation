# Configure the Sidekick

The **Sidekick** is the AI assistant built into Luna Park.

Open the panel with `Ctrl + Shift + F`, then go to the **Sidekick** tab (next to **Navigator** and **Finder**).

<DImage :src="Popup" alt="Popup opened on the Sidekick tab" />

## Configure a provider

Three providers supported: **Gemini**, **Anthropic**, **OpenRouter**. For each:

1. Select the provider.
2. Enter your `API Key`.
3. Pick the model.

<DImage :src="ProviderConfig" alt="Provider configuration with API Key and model selection" />
