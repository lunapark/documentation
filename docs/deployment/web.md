# Web App

The web version of your application is a **single-page application** (Vue, built with Vite), served by its Node.js backend or by any static host. It is what you get when you [compile](./compilation) your project, from the cloud version or the desktop app. To put it online, see [Self-hosting](./deployment).

## General settings

The settings are available in the **General** section of the <LIcon :icon="faCog"/> **Settings** [workspace](../workspace/editor#the-workspace). You can change the name of your application there, and choose the history mode:

- **Web Mode** (default): Generates links like `myApp.com/home/dashboard`. This mode is required for [SEO](./seo). The backend of the exported app answers every page path with the app; on a static host, redirect the paths that match no file to the `index.html` file.
- **Hash Mode**: Generates links like `myApp.com/#/home/dashboard`. This mode works on any static host without configuration, but is not suited for SEO and does not work with page anchors.
- **Memory Mode**: Generates links like `myApp.com/` (the path is hidden). This mode works in all conditions but is not suited for SEO.

[Desktop](./desktop) and [mobile](./mobile) apps always use Hash Mode.

The title, description, and social image of the pages are set in the **SEO** section, see [SEO](./seo).

## Progressive Web App

A Progressive Web App (PWA) can be installed from the browser, on a computer or a phone: it gets an icon, opens in its own window, and loads its interface without the network once installed.

Enable it with the checkbox of the **Progressive Web App** section of the <LIcon :icon="faCog"/> **Settings** workspace:

| Setting | Default | Description |
|---|---|---|
| **Enabled** | Off | Turns the app into a PWA. |
| **Short name** | App name | The name shown under the icon, when space is limited. |
| **Description** | Empty | A short description of the app. |
| **Icon (512×512)** | Luna Park icon | The URL of a square 512×512 image used as the app icon. |
| **Theme color** | `#ffffff` | The color of the title bar and of the browser interface around the app. |
| **Background** | `#ffffff` | The color of the splash screen shown while the app starts. |
| **Display** | Standalone | **Standalone** (own window, like a native app), **Fullscreen**, **Minimal UI** (own window with basic navigation buttons), or **Browser** (regular tab). |
| **Orientation** | Any | Locks the screen orientation: **Any**, **Portrait**, or **Landscape**. |

The compiled app then includes a web app manifest and a service worker. The service worker caches the frontend files (HTML, CSS, JS, images, fonts) and updates them automatically when you deploy a new version. Requests to the backend (`/api`) always go to the server.

::: info
- Browsers only offer to install a PWA served over **HTTPS** (or from `localhost`).
- The service worker is only generated by the production build: test the installation with **Production** in the desktop app, not with **Watch**.
- Desktop and mobile apps ignore this option.
:::

## Backend settings

The **Backend** section of the **Settings** workspace sets an outgoing **Proxy** for the backend and the **Cookie salt** used to sign cookies. Refreshing the salt invalidates existing sessions.
